

AquaSentinel 🌧️
Urban Waterlogging Crisis Management System

A Java-based GUI desktop application that allows citizens to report 
waterlogging incidents across Mumbai. Authorities can monitor affected 
zones, track severity, and respond to high-priority areas in real time.

🛠️ Tech Stack
- Java (Swing GUI)
- JDBC
- MySQL


📌 Features
- User & Admin login system
- Waterlogging report submission
- Area-wise dashboard
- Auto-priority flagging for high-risk zones
- Real-time alert panel


🗄️ Database
MySQL database: `aquasentinel`
Tables: `users`, `reports`, `zones`


▶️ How to Run
1. Clone this repository
2. Set up MySQL and run the SQL schema file
3. Update DB credentials in `DBConnection.java`
4. Run `Main.java` in IntelliJ IDEA
